	# The first technology is anchored to the vanilla tech_trucks grid box in

	# create a renderable technology branch in the country tech-tree GUI.

	# The infantry folder uses the "LEFT" gridbox format (x = down, y = right,
	# slot 70 px) and has one gridbox per branch chain.  The tachanka line
	# inherits the tech_trucks_tree gridbox (origin 140x620) from its anchor,
	# so: pixel row = 620 + x * 70, pixel column = 140 + y * 70.
	#
	# Layout rules (see tools/tech_tree_layout.py for the live map):
	#   * the vanilla armored cars occupy folder row x = 4 (pixel row 900).
	#     The tachanka branch must NOT share that row, otherwise the branch
	#     reads as a continuation of the armored-car chain.
	#   * the whole "Специальные войска" block starts with the section header
	#     (INFANTRY_TITLE_SPECIAL, pixel rows 950..1012) and the marines
	#     chain (1035) and ends with the special-forces chain (1490..1630);
	#     the last vanilla row is 1630, i.e. the tree is occupied down to
	#     pixel row 1700.
	#   * the tachanka branch therefore uses folder row x = 16 (pixel row
	#     1740): below the armored cars AND below the whole special-forces
	#     block, so nothing can overlap it.
	#   * columns y = 2/5/8/11 (pixel columns 280/490/700/910) keep the branch
	#     inside the visible part of the tree (the folder background is 1400 px
	#     wide) where no vanilla technology is drawn; the 3-slot (210 px) step
	#     keeps the four nodes from overlapping each other.
	#
	# There is deliberately no path to the armored-car chain: the branch is
	# reachable only from tech_trucks, which supplies the grid box.
	# -------------------------------------------------------------------------
