	#   * the vanilla armored cars occupy folder row x = 4 (pixel row 900).

	#     reads as a continuation of the armored-car chain.

	#     drawn at pixel rows 950..1012 on the left edge of the folder, and the
	#     marines chain starts at pixel row 1035.
	#   * the tachanka branch therefore uses folder row x = 6 (pixel row 1040):
	#     two rows below the armored cars, below the special-forces header and
	#     clear of every vanilla chain (the vanilla tree ends at pixel row
	#     1700, the bottom of the special-forces block).
	#   * columns stay on the empty right side (y = 24/27/30/33, pixel columns
	#     1820/2030/2240/2450) where no vanilla technology is drawn, and the
	#     3-slot (210 px) step keeps the four nodes from overlapping each other.

	# There is deliberately no path to the armored-car chain: the branch is
	# reachable only from tech_trucks, which supplies the grid box.
