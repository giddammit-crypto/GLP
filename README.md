# Анархия! - Гуляйпольская Республика — GLP

Модификация для Hearts of Iron IV (1.19.*).

## Требования

- **Обязательно: DLC «La Résistance»** (1.9, 2020). Лидер Махно задан как
  `ideology = anarchism` (`common/characters/GLP_characters.txt`) — это
  ванильная идеология, добавленная данным DLC (путь CNT-FAI Испании).
  Без DLC игра не знает идеологию `anarchism` и будет ронять ошибку при
  загрузке сценария на персонаже `GLP_nestor_makhno` (флаг лидера
  `GLP_anarchism.tga` тоже существует только для этой идеологии).

## Описание
Альтернативно-историческая модификация, добавляющая Гуляйпольскую Республику (Вольную территорию) под предводительством Нестора Махно с уникальным древом национальных фокусов, персонажами, решениями, событиями, музыкой и графикой.

## Ключевые решения
- **Иконки фокусов** — тематические ванильные спрайты базовой игры (`GFX_goal_generic_*` / `GFX_focus_generic_*`, 118 уникальных на 190 фокусов). Список проверен по ванильному `interface/goals.gfx`: без DLC-зависимых спрайтов. Соответствие: `tools/focus_icons_vanilla.tsv`.
- **Иконки национальных духов** — все 119 духов используют тематически подобранные **ванильные** иконки (подбор по справочнику [hoi4-icon-search](https://wyandotte.github.io/hoi4-icon-search/)): только семейство `GFX_idea_generic_*` базовой игры, без DLC-зависимостей. Собственный пак `GFX_idea_GLP_*` упразднён и удалён. Соответствие: `tools/idea_pictures.tsv`.
- **Картинки событий/новостей** — у каждой новости Гуляйполя свой **чёрно-белый фотоснимок по тематике сюжета** (тачанки, бронепоезд, съезды, ярмарка, флот, авиаэскадрилья и т.д.), собранный строго в ванильном формате **397×153** (эталон: `news_event_001.dds`) — снимок встаёт в лист новости пиксель-в-пиксель под нашу рамку. Карта «событие → картинка»: `tools/event_pictures.tsv` (сверяет аудит).
- **Звания командиров** — исторически у махновцев званий не было: ванильные `GENERAL` / `FIELD_MARSHAL` / `ADMIRAL` переопределены словом **«Командир»** (RU) / **«Commander»** (EN). Ограничение: переопределение глобально — слово видно и у генералов других стран.
- **Окно новости** — `interface/eventwindow.gui` (полная ванильная копия) с окном `EventWindow_News`, расширенным по горизонтали ×2. Ванильный газетный фон убран: собственный `GFX_GLP_event_news_bg` (тёмная состаренная бумага, золотая ар-нуво рамка, 1056×595), снимок обрамлён собственной рамкой `GFX_GLP_news_pic_frame` (тень+бордюр); заголовок — display-шрифт `hoi_24header`, текст — читаемый `hoi_18mbs`.
- **Загрузочный экран** — наши цитаты `LOADING_TIP_*` (RU/EN, полное перекрытие ванильных 1..256) выводятся в **ванильной металлической панели** `GFX_loadingtip_bg` на её ванильном месте (низ экрана, `CENTER_DOWN`). Кастомная центральная панель с журнальной подложкой удалена. Статус и прогресс-бар загрузки сохранены; цитаты в арт экранов не запекаются.
- **Вечные фокусы** — панель 770×380 поставлена по центру под всем деревом (`x=2385`, `y=2600`), с безопасным зазором 132 px после нижнего ряда; на обычные фокусы она не наезжает.
- **Персонажи** — 16 фиксированных персонажей (Махно, Григорьев, Каретник, Щусь, Белаш, Задов, Кузьменко, Волин, Богдан Дыбец, Алексей Дыбец, Феодосий Кожин, Корнилов, Дроздовский + 3 союзные миссии), у всех собственные портреты (156×210 large / 88×119 medium / 65×67 advisor small — размеры подтверждены ванилью и вики). Все 16 портретов перегенерированы в высоком качестве (единая студийная стилистика, градация с виньеткой под HOI4). У командиров Гуляйполя знаков различия нет (без кокард, погон, звёзд; отличительный знак — чёрная лента на папахе, как у Семёнова); у белых союзных генералов царская форма оставлена историчной. Случайные ванильные generic-советники удаляются на `on_startup` (см. `common/on_actions/GLP_on_actions.txt`).
- **Модели войск** — из Rise of Russia (Revolution or Reaction): **пехота анархистов** — чёрный бушлат с пулемётными лентами крест-накрест (`RSR_marine`, красная звезда/полоса перекрашены; tag-specific `GLP_infantry_entity`), **казачья конница** — `DON_cavalry` + шашка (tag-specific `GLP_cavalry_entity` / `GLP_cavalry_2_entity`), **белые добровольческие части**: корниловская ударная кавалерия `KORN_cavalry` (фуражка с красным околышем) и дроздовские штурмовики `DROZD_stormtroopers` — через уникальные подразделения `kornilovtsy` / `drozdovtsy` (только эти дивизии; см. `common/units/GLP_white_units.txt`). Все сущности собраны явно **без** `clone` ванильных (явные стейты + attach, паттерн RSR); отдельных моделей махновцев в ROR нет — взяты тематически ближайшие.

## Структура мода
- `common/` — фокусы, идеи, персонажи, решения
- `events/` — события и новостная лента
- `gfx/` — флаги, портреты, экраны и иконки идей (мастера 2D-сборки — `_src_*`)
- `history/` — история страны, OOB, стейты
- `interface/` — GUI-оверрайды и .gfx
- `localisation/` — русский/английский (UTF-8 BOM)
- `music/` — Монгол Шуудан

## Инструменты разработчика
- `tools/glp_audit.py` — аудит (синтаксис, дубли, локализация, спрайты, тематические иконки всех духов, карта картинок новостей, геометрия панели вечных фокусов, ванильная геометрия панели цитат, размеры DDS, 3D-модели, реальная прозрачность альфы, GUI-оверрайды). Код возврата 1 при ошибках.
- `tools/build_portraits.sh` — сборка портретов.
- `tools/build_screens.sh` — сборка экранов загрузки (1920×1080 DXT1, титры без цитат).
- `tools/build_news_bg.sh` — сборка оформления окна новостей (фон газеты 1056×595 RGBA + рамка снимка 405×161 DXT5).
- `tools/build_event_pictures.sh` — картинки событий-новостей: ч/б газетное фото 397×153 из мастеров `_src_news_*` (карта — `tools/event_pictures.tsv`).

## Элитные белые части (фокус «Старые враги»)
Награда фокуса: 2 корниловские ударные + 2 дроздовские стрелковые дивизии (ветераны 0.75, полное снаряжение), генерал **Корнилов** (черты «Ледяной поход»: +12% кавалерия/прорыв, −10% скорость подготовки; «Легенда Добрармии»: +8% ОРГ, +5% мораль, +10% разведка, −5% план) и полковник **Дроздовский** (черты «Железная дисциплина»: +12% оборона, +5% ОРГ, −8% атака; «Последний батальон»: −10% вне снабжения, −10% потребление, −5% скорость). Призываются командирами вместе с их частями.

## Трофейные команды РПА
При победе войск Махно в бою (`on_army_leader_won_combat`, FROM = GLP): шанс 65% — трофейное стрелковое вооружение и снаряжение, 45% — мототехника, 15% — танки и артиллерия; при наличии людских резервов (8000+) и вооружения в запасах формируется новая дивизия «Трофейный отряд РПА» (в составе — ремонтная рота) на контролируемой территории, с кулдауном 30 дней. Механика активна только при изученной технологии **ремонтной роты** (`tech_maintenance_company`) и наличии шаблона с ремонтной ротой в армии (`has_template_containing_unit = maintenance_company`) — точный пословный синтаксис из ванильного `armor.txt`.
