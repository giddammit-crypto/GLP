# Анархия! - Гуляйпольская Республика — GLP

Модификация для Hearts of Iron IV.

## Описание
Альтернативно-историческая модификация, добавляющая Гуляйпольскую Республику (Вольная территория) под предводительством Нестора Махно с уникальным древом национальных фокусов, персонажами, решениями, событиями, музыкой и графикой.

## Структура мода
- `descriptor.mod` — метаданные мода
- `common/` — национальные фокусы, идеи, персонажи, страны, решения и советники
- `events/` — цепочки событий
- `gfx/` — графические элементы, флаги, портреты лидеров/генералов, загрузочные экраны, иконки
- `history/` — история страны, начальное размещение войск и конфигурация регионов
- `interface/` — элементы интерфейса и gfx-определения
- `localisation/` — локализация (русский, английский)
- `music/` — музыкальное сопровождение

## Инструменты разработчика
- `tools/glp_audit.py` — автоматический аудит мода (синтаксис, дубли ID, локализация с BOM, целостность спрайтов, геометрия .dds). Запуск: `python3 tools/glp_audit.py`, код возврата 1 при ошибках.
- `tools/build_portraits.sh` — сборка портретов персонажей из мастеров `_src_*.jpg` в .dds по спецификации 1.19.2 (большие 156x224 ARGB8888, малые и иконки советников 156x210 DXT5). Требуется ImageMagick.
- `tools/build_screens.sh` — сборка экранов загрузки (1920x1080 DXT1, перекрытие ванильных `load_1..load_16`), фона главного меню и логотипа с подписью «Разработчик — Амброзиев О.А.».

Отчёт последнего аудита: [`AUDIT_REPORT.md`](AUDIT_REPORT.md).
