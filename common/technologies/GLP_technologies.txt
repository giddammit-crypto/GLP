	# The first technology is anchored to the vanilla tech_trucks grid box in
	# zzz_GLP_tachanka_anchor.txt.  A folder/position block alone does not
	# create a renderable technology branch in the country tech-tree GUI.
	#
	# The infantry folder uses the "LEFT" gridbox format (x = down, y = right)
	# and has one gridbox per branch chain.  The tachanka line inherits the
	# tech_trucks_tree gridbox (the motorized row) from its anchor.
	#
	# Prior layout bug: positions {x=5,y=3/4/5/7} put the four tachanka
	# technologies only one slot (70 px) apart, so they overlapped each other,
	# and the row (y = 970) sat five pixels above the marines chain and
	# directly below the armored-car chain, causing visual overlap with both
	# vanilla branches.
	#
	# Corrected layout: vanilla infantry research items are spaced two slots
	# (140 px) apart on a row.  We therefore place the branch on row x = 6
	# (pixel row y = 1040, safely below the armored-car row at y = 900 and
	# below the marines row at y = 965), and use y = 15/17/19/21
	# (pixel columns x = 1190/1330/1470/1610) so the four nodes use the
	# vanilla 140 px spacing and stay far to the right of the marines,
	# mountaineers, paratroopers and armor-car columns.
	# -------------------------------------------------------------------------
