# Анархия! - Гуляйпольская Республика — GLP

Модификация для Hearts of Iron IV (1.19.*).

## Описание
Альтернативно-историческая модификация, добавляющая Гуляйпольскую Республику (Вольную территорию) под предводительством Нестора Махно с уникальным древом национальных фокусов, персонажами, решениями, событиями, музыкой и графикой.

## Ключевые решения
- **Иконки фокусов** — тематические ванильные спрайты базовой игры (`GFX_goal_generic_*` / `GFX_focus_generic_*`, 77 уникальных на 190 фокусов). Список проверен по ванильному `interface/goals.gfx`: без DLC-зависимых спрайтов. Соответствие: `tools/focus_icons_vanilla.tsv`.
- **Иконки национальных духов** — 15 собственных иконок (60×68, несжатый RGBA, реальная прозрачность — как ванильные `gfx/interface/ideas/generic_*.dds`) + тематические ванильные generic-спрайты только базовой игры. Соответствие: `tools/idea_pictures.tsv`.
- **Картинки событий/новостей** — ванильный формат **397×153** (эталон: `news_event_001.dds`); 16:9-картинки растягивали окно новости.
- **Окно новости** — `interface/eventwindow.gui` (полная ванильная копия) с окном `EventWindow_News`, расширенным по горизонтали ×2; фон — `GFX_event_news_bg_wide` (9-slice из ванильной газеты, 1056×595).
- **Загрузочный экран** — `interface/load_screen.gui` (правильное ванильное имя файла): ванильная металлическая панель цитат удалена, цитаты `LOADING_TIP_*` выводятся текстбоксом у нижней кромки (отступ 15 px); статус и прогресс-бар загрузки сохранены. Цитаты в арт экранов больше не запекаются.
- **Персонажи** — 14 фиксированных персонажей (Махно, Григорьев, Каретник, Щусь, Белаш, Задов, Кузьменко, Волин, Богдан Дыбец, Алексей Дыбец, Феодосий Кожин + 3 союзные миссии), у всех собственные портреты (156×210 large / 88×119 medium / 65×67 advisor small — размеры подтверждены ванилью и вики). Случайные ванильные generic-советники удаляются на `on_startup` (см. `common/on_actions/GLP_on_actions.txt`).

## Структура мода
- `common/` — фокусы, идеи, персонажи, решения
- `events/` — события и новостная лента
- `gfx/` — флаги, портреты, экраны, иконки идей (мастера сборки — `_src_*`)
- `history/` — история страны, OOB, стейты
- `interface/` — GUI-оверрайды и .gfx
- `localisation/` — русский/английский (UTF-8 BOM)
- `music/` — Монгол Шуудан

## Инструменты разработчика
- `tools/glp_audit.py` — аудит (синтаксис, дубли, локализация, спрайты, ванильные белые списки иконок, размеры DDS 60×68/397×153/156×210/88×119/65×67/1920×1080, реальная прозрачность альфы, GUI-оверрайды, техимена в локализации). Код возврата 1 при ошибках.
- `tools/build_portraits.sh` — сборка портретов.
- `tools/build_screens.sh` — сборка экранов загрузки (1920×1080 DXT1, титры без цитат).
- `tools/build_event_pictures.sh` — картинки событий (397×153).
